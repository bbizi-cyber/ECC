# Справочник фан-эдитов пользователя

## When to Use

- Пользователь просит эдит про актёра, героя, фильм или знаменитость.
- Пользователь присылает новые примеры: разобрать их тем же способом и дописать сюда новым номером.
- Нужно выбрать приёмы, ритм, текст, цвет, формат или источники для эдита.

## How It Works

- Каждый присланный ролик — пример. Не копировать один, а собирать лучшее из нескольких.
- Перед монтажом выбрать 3–5 приёмов из списка «Приёмы, из которых собирать» и назвать пользователю, из каких примеров они взяты.
- Тайминги ниже замерены покадрово: склейки — ffmpeg scene-detect, бит — librosa, движение — ORB, вспышки — по яркости кадра.
- Соблюдать раздел «Предпочтения пользователя» в конце.
- Готовые переходы в `scripts/transitions.py` (numpy/OpenCV, кадры RGB uint8): `match_dissolve` (match-cut с выравниванием силуэта, №16), `card_stack` (стопка карточек на бит, №16), `flip180` (кадр вверх ногами, №15–16), `window_reveal` (окно-превью следующего кадра за полудара до склейки, №31), `zoom_through` (ускоряющийся наезд ×2,4 в объект → склейка на тот же объект, №32), `punch_settle` (вход с зумом +14 % и выезд за 4 кадра, №32), `tilt_snap` (наклон 6,5° → щелчок на удар, №32), `spin_out` (проворот ~20° со смазом в следующий кадр, №32), `quick_blend` (растворение за 2 кадра, №31–32), `creep_zoom` (постоянный наезд ~0,9 % за кадр, №32), `luma_burn` (прожиг: светлое следующего кадра проступает сквозь тёмное → призрак → вертикальный смаз, №33), `flash_in` (пересвет → сиреневато-белый кадр → тёплый выбеленный вход, №33), `vsmear` (кадр с вертикальным смазом, №33), `grain` (плёночное зерно, №33), `face_morph` (лицо в лицо: чужое лицо, совмещённое по детектору лиц, проступает жёстким ч/б и уходит с глитч-полосками, №34), `echo_to_bw` (цвет → яркий ч/б через эхо, №34), `vanish_flicker` (мерцание «есть герой / пустой кадр», №34), `engrave_text` (слово, вдавленное в стену, №34), `stencil` (трафаретный портрет в 2 уровня, №34), `face_anchor` + `face_lock` (поставить лицо на ту же точку и в тот же размер, что в прошлом кадре, по глазам), `pingpong` (чередование двух героев в одинаковом кадре по 6 кадров, №34).
- Все инструменты лежат в `scripts/` (Python, OpenCV), рабочая папка задаётся переменной `FAN_EDIT_WORK` (по умолчанию `~/fan-edits`):
  - модели: `python fetch_models.py` (YuNet, SFace, U²-Net, Real-ESRGAN);
  - `faceid.py` — найти нужного актёра в кадре (YuNet + SFace); `shotscan.py` — склейки и лицо актёра по всем клипам;
  - `pairfinder.py` — пары для идеального перехода: тот же актёр, тот же ракурс, разные фильмы (силуэт + лицо, поворот головы); `--backs` — ещё и кадры со спины;
  - `matchframe.py` — тот же момент в другой версии фильма; `trans_probe.py` — покадровый замер переходов в примерах;
  - `look.py`, `look_fem.py` (серебристый ч/б с ореолом), `fx.py`, `extras.py` (маска человека, оптический поток для слоу-мо, лица), `sfx.py`, `sr.py`;
  - готовые монтажи как образцы: `examples/render_mcconaughey.py`, `examples/drive_render.py`, `examples/fem_render.py` + `shots_fem.py`.
- Эталон — №34. Главное в нём (слова пользователя): маленькие переходы между героями в одном положении. Подбирать соседние кадры так, чтобы лицо было на той же точке экрана и того же размера, остаток добирать `face_lock` (зум не больше ×1,3). Затем идея фильма в переходах, ритм (длинные планы чередуются с очередями) и тишина перед дропом.

## Каждый эдит — новый

Правило пользователя: каждый новый эдит должен быть другим; похожие на прошлые не подходят.

- Перед монтажом сверить план с «Журналом сделанных эдитов» ниже. Новый эдит обязан отличаться минимум по четырём осям из шести: тип хука, структура/драматургия, главный переход, стиль текста, цвет, темп/ритм склеек.
- Никогда не повторять: ту же песню, тот же первый кадр, тот же титр/шрифт заголовка, ту же связку «хук → дроп» один в один.
- Приёмы из справочника комбинировать каждый раз по-новому; если приём уже был «фишкой» прошлого эдита, в новом он может быть только второстепенным или его нет.
- После сдачи дописать эдит в журнал.

## Два вида эдитов: «мужские» и «женские»

Пользователь делит эдиты на два вида и, присылая пример, пишет, какой он.

Порядок работы: для каждого человека сначала мужской эдит, сразу за ним женский с тем же человеком (так было с Макконахи и Гослингом). Женский должен отличаться от мужского по тем же шести осям, что и любые два эдита. Записывать вид в заголовок разбора, а при сборке нового эдита брать приёмы в первую очередь из примеров того же вида.

- **Мужские** — примеры №1–11, №13–16, №31–36 этого справочника и эдиты, сделанные по ним: Макконахи (Scarface-стиль), Гослинг × «Драйв» × Nightcall. Харизма, сила, тьма, ночь; удары на бит, белые вспышки, неон, кинетический текст.
- **Женские** — №12, №17–30 («Мистер и миссис Смит»: ч/б, «война → любовь», длинные планы, мягкие вспышки) и эталон — эдит из сессии «Приветствие» (Макконахи, «Как отделаться от парня за 10 дней»). Вертикаль 1080×1920, картинка во всю ширину чуть выше центра; хук — одна романтичная реплика из фильма со звуком, субтитры появляются по словосочетаниям в чёрном поле под кадром; музыка под репликой приглушена, сразу после — дроп и склейки на каждый бит; тёплый мягкий грейд со свечением (romcom glow), улыбки, взгляды, финал — поцелуй; в конце маленький ник на чёрном с тёплым свечением (@editsfrgrl).

  - Порядок: общий план → средний → крупный рассказчик → Тайлер на 2 кадра («25-й кадр», как в самом фильме).
  - Сразу за ней крупный план рассказчика с тряской и смазом.
- Дальше ритм «дышит»: планы ~1 с сменяются очередями коротких по 0,2–0,37 с на доли бита (по онсетам).
- 19,7 → 20,07 с, **появление**: тот же кадр у окна сначала без Тайлера, потом с ним. Он «появляется» на ударе.
- 22,6 → 23,0 с, **подмена героя**: в той же светлой зелёной комнате Тайлер (быстрый наезд 4,4 % за кадр), потом на его месте рассказчик.
- 23,17 с: лицо на полу, кадр повёрнут на 90°. 23,7 с: наклон-поворот.
- 24,07–25,5 с: драка на парковке. Общий план → на удар вставка крупного → снова общий.
- 26,43 с, **исчезновение**: у хранилища Тайлер исчезает из того же кадра.
- 26,93–27,67 с: мерцание «есть Тайлер / пустая стена» (8 / 4 / 3 / 8 кадров). Потом на пустой стене проявляется вдавленное слово POWER: антиква, разрядка, чуть светлее стены.

**Финал (27,7–31 с)**
- Порядок: 0,67 с черноты → трафаретный портрет Тайлера 0,87 с → чернота 0,77 с → портрет крупнее 0,7 с → конец.
- Трафарет в 2 уровня: ~79 % чёрного, ~7 % белого. Музыка в это время затихает.
- Цвет — родной цвет фильма с задавленным чёрным, местами холодно-зелёный. Из текста только одно слово.

**Почему идеал**
1. Маленькие переходы между героями в одном положении: лицо на той же точке и того же размера, пинг-понг по 6 кадров (слова пользователя).
2. Переходы несут смысл фильма: лицо в лицо, «25-й кадр», появление и исчезновение, подмена героя.
3. Хук-диалог без музыки → почти тишина → дроп.
4. Ритм дышит: длинные планы сменяются очередями.
5. Минималистичный финал: чернота и трафарет.
