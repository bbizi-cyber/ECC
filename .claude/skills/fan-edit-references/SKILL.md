# Справочник фан-эдитов пользователя

## When to Use

- Пользователь просит эдит про актёра, героя, фильм или знаменитость.
- Пользователь присылает новые примеры: разобрать их тем же способом и дописать сюда новым номером.
- Нужно выбрать приёмы, ритм, текст, цвет, формат или источники для эдита.

## How It Works

- Каждый присланный ролик — пример. Не копировать один, а собирать лучшее из нескольких.
- Перед монтажом выбрать 3–5 приёмов из списка «Приёмы, из которых собирать» и назвать пользователю, из каких примеров они взяты.
- Тайминги ниже замерены покадрово: склейки — ffmpeg scene-detect, бит — librosa, движение — ORB, вспышки — по яркости кадра.
- Соблюдать раздел «Предпочтения пользователя» в конце.

## Examples

- «Сделай эдит про Райана Гослинга»: хук-фраза из интервью (№7–9), заголовок «THE MANY FACES OF …» по словам (№11), крупные планы ролей с угловыми подписями (№11), одна страница-коллаж с белой вспышкой (№6), ник в конце.
- «Вот ещё пример»: разобрать по той же схеме и добавить раздел №12.

## Разборы
Правило пользователя: каждый присланный ролик — пример. Не копировать один, а собирать лучшее из всех.
Тайминги замерены покадрово: склейки — scene-detect, бит — librosa, движение камеры — ORB, вспышки — по яркости кадра.
Хвост 3–5 с в конце каждого ролика — заставка TikTok, её добавляет платформа, в эдит не входит.

### 1. Scarface с песней — @musafx (4:3, 22 с, ~136 BPM). Первый пример, по нему сделан эдит с Макконахи
- Вступление: слова песни по одному по центру, мелкий белый текст; акцентные слова на 3 кадра крупно и цветом (красный, жёлтый, оранжевый).
- Дроп на 6,3 с: 1 белый кадр, затем склейки на каждый бит.
- Белые вспышки: ровно 1 кадр чистого белого, следующий кадр уже чистый.
- Переход: белый квадрат → маленькое окно-вставка со следующим кадром → белая вспышка → полный кадр.
- Второй круг (13,4 с) повторяет цепочку кадров; в конце ник на чёрном.

### 2. The Mentalist (Саймон Бейкер) — @tekno_edit (1:1, 16 с, ~85 BPM)
- Спокойный «харизматичный» эдит без текста и без вспышек.
- Склейки строго каждые 0,70 с.
- На склейках лёгкие наезды/отъезды (зум ±1–2%) и поворот на 1–2,5°: мягкие «доводки», а не тряски.
- Цепочка из ~11 кадров проигрывается дважды (0–8 с и 8–16 с).
- Цвет: холодный, приглушённый, серо-бирюзовый; сам кадр всё время из одного сериала.

### 3. «Духless» — @elegantbaza (16:9, 45 с). Кинетическая типографика
- 0–35 с: сцена диалога со звуком из фильма, реплики слово за словом прямо в кадре.
- Шрифты: узкий жирный гротеск заглавными (белый) + маленькие курсивные слова рядом; ключевые слова красным («ПРОСРАЛ», «ДЕНЬГИ», «КРЫСА»).
- Текст стоит рядом с говорящим, позиция меняется от фразы к фразе.
- Огромные полупрозрачные светло-серые слова на весь кадр на акцентах («БУМАЖКИ», «БАБКИ», «СУКА»).
- Камера трясётся на выкрикнутых словах; красное лого фильма «ДУХLESS» перед развязкой.
- 35–45 с: музыкальная часть, склейки каждые ~0,45–0,5 с.

### 4. Scarface ч/б — @musafx (4:3, 12,5 с). Тот же автор, что №1
- Почти ч/б, тёплая сепия, приглушённый цвет.
- Белые вспышки на 3,37 / 5,07 / 6,50 / 11,37 с.
- Короткая тряска с поворотом (3,0–3,2 с); резкие отъезды-удары на склейках (зум −5…−8%).
- 11,0–11,3 с: отъезд с вращением (~2% и −1° за кадр), затем удар-наезд ×1,19.
- Без текста.

### 5. Fight Club — @lofin_edits (1:1, 20,5 с)
- 0–7,3 с: тёмное медленное вступление (нож, лицо) с плавным наездом ~1,5–2% за кадр, бирюзово-зелёный цвет фильма.
- Дроп на 7,27 с с белой вспышкой; дальше склейки каждые ~0,47 с (≈128 BPM).
- Вспышки на 7,27 / 11,53 / 14,37 / 18,63 с.
- 12,47 с: зум-переход (отъезд ×0,58 с поворотом 4,5°); на 13,9–14,2 с короткие зум-пульсы.
- Конец: чёрный.

### 6. Журнальный коллаж Макконахи — @kamiae00 (1:1, 11,5 с, ~85 BPM)
- Строгая сетка: событие каждые 17 кадров (0,71 с), 16 раз подряд.
- Чередование: страница-коллаж → 4 кадра из фильмов → страница-коллаж → 4 кадра.
- Карточки ч/б внахлёст, статичные; перед каждой 1 кадр белого прямоугольника её размера; у части тонкая белая рамка.
- Первая карточка 2-й страницы: белая заливка уезжает вниз за ~8 кадров.
- Фон 1-й страницы — живой ч/б дым, 2-й — чёрный.
- Текст: мелкие курсивные заглавные с разрядкой («M A T T H E W», вертикальное «M C C O N A U G H E Y», «G O A T»).
- Цвет: насыщенность 6–8, контраст 27–29, тёплые тени. Кадры из фильмов — без эффектов.

### 7. Макконахи, ток-шоу → фото — @godsplanarchive (4:3, 11 с, 129 BPM)
- 0–4,2 с: хук — Макконахи смеётся на ток-шоу, звук живой, музыка почти без баса.
- Дроп на склейке (бас ×6).
- Фото на БЕЛОМ фоне, резкая склейка на каждый бит (14 кадров = 0,47 с), точность 0,02–0,07 с.
- Фото разного размера и в разных местах; иногда 2 рядом; одна с крупным жирным белым «God's plan».
- Финал: кадр из «Настоящего детектива» во весь экран.

### 8. Брэд Питт, «Между двумя папоротниками» → коллаж — @palaaedits (4:3, 20 с, 129 BPM)
- 0–12 с: длинный смешной диалог (Питт и Галифианакис) как хук.
- Дроп на 12 с: карточки на белом, 2–3 штуки лесенкой внахлёст, одна большая + маленькие сбоку.
- Микс фото и кадров (F1, «Бойцовский клуб», «Однажды в Голливуде»).
- Конец: ник «palaaedits» на белом.

### 9. Макконахи, речь на «Оскаре» → фото — @godsplanarchive (4:3, 12,6 с, ~118 BPM)
- 0–7,1 с: речь на «Оскаре» как хук.
- Дроп: карточки на белом лесенкой вниз-вправо (3 штуки, по одной на удар), потом интервью во весь кадр, снова карточки.
- Логотип-гравюра «GODSPLAN» с орлом; «God's plan» поверх фото.

### 10. Брэд Питт, фильмография — @freshcuppa (16:9, 64 с, ~123 BPM)
- Вступление: «And the Oscar goes to… Brad Pitt».
- На каждую роль по центру: имя героя крупно (геометрический гротеск), под ним курсивом фильм, над ним мелко золотом «Oscar Winner / Nominated».
- Реплики героев субтитрами тонкими заглавными по словам, со звуком из фильма.
- Две паузы-«вдоха» (32 и 60 с): музыка затихает под реплику.

### 11. «The many faces of Brad Pitt» — @themntlst (16:9, 19 с, ~120 BPM)
- 0–4,27 с: крупный план из «Семи», заголовок собирается по слову: THE / MANY / FACES / OF / BRAD PITT;
  жирный гротеск заглавными, белый с тенью; на бит имя на ~0,5 с жёлтое, потом снова белое.
- Дальше одна роль на ~1,0 с (каждые 2 удара), склейки точно на бит.
- Все кадры — крупные планы лица в похожей крупности, почти без движения.
- Подпись в правом верхнем углу мелким курсивом: «Aldo Raine in "Inglorious Bastards" (2009) by Quentin Tarantino».

### Приёмы, из которых собирать (откуда брать)
- Хук со звуком (интервью, речь, диалог), музыка под ним приглушена → дроп: №7, 8, 9, 3, 5.
- Заголовок по словам с цветным акцентом на бит: №11; слова песни по одному: №1.
- Кинетическая типографика реплик, огромные полупрозрачные слова, красные акценты: №3.
- Подписи ролей: «имя героя + фильм» (№10) или угловая «X in "Film" (год) by режиссёр» (№11).
- Карточки на белом (№7–9) или чёрном/дыме с белой вспышкой (№6).
- Белые вспышки на 1 кадр, окно-вставка: №1, 4, 5. Мягкие зум-доводки на склейках: №2. Зум-переход с поворотом: №4, 5.
- Строгая сетка склеек (0,47 / 0,70 / 1,0 с) — во всех; склейки точно на бит.
- Цвет: сепия/ч/б (№4, 6), холодный приглушённый (№2), родной цвет фильма (№5, 10, 11).

### Предпочтения пользователя
- Только HD-исходники, без видимой пикселизации и без апскейла из низкого разрешения.
- Источники: clip.cafe (поиск по фразе), YouTube через vidIQ video_upload (бесплатно, 1080p), трейлеры 1080p на Dailymotion.
- Музыка: из присланного примера или с YouTube через vidIQ (1 кредит); трендовые звуки — vidiq_tiktok_trending_sound_search.
- Вид для TikTok: 1080×1920, картинка 16:9 во всю ширину на 40 px выше центра, сверху и снизу чёрное.
- Подпись автора в конце: мелко, полупрозрачно, на чёрном (@editfrmn).
- Звуки «вжух» не нужны. Тряски — только на акцентах. Выстрел — один.
