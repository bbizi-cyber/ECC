# Справочник фан-эдитов пользователя

## When to Use

- Пользователь просит эдит про актёра, героя, фильм или знаменитость.
- Пользователь присылает новые примеры: разобрать их тем же способом и дописать сюда новым номером.
- Нужно выбрать приёмы, ритм, текст, цвет, формат или источники для эдита.

## How It Works

- Каждый присланный ролик — пример. Не копировать один, а собирать лучшее из нескольких.
- Перед монтажом выбрать 3–5 приёмов из списка «Приёмы, из которых собирать» и назвать пользователю, из каких примеров они взяты.
- Тайминги ниже замерены покадрово: склейки — ffmpeg scene-detect, бит — librosa, движение — ORB, вспышки — по яркости кадра.
- Соблюдать раздел «Предпочтения пользователя» в конце.

## Два вида эдитов: «мужские» и «женские»

Пользователь делит эдиты на два вида и, присылая пример, пишет, какой он. Записывать вид в заголовок разбора, а при сборке нового эдита брать приёмы в первую очередь из примеров того же вида.

- **Мужские** — примеры №1–11, №13–16 этого справочника и эдиты, сделанные по ним: Макконахи (Scarface-стиль), Гослинг × «Драйв» × Nightcall. Харизма, сила, тьма, ночь; удары на бит, белые вспышки, неон, кинетический текст.
- **Женские** — №12 («Мистер и миссис Смит»: ч/б, «война → любовь», длинные планы, мягкие вспышки) и эталон — эдит из сессии «Приветствие» (Макконахи, «Как отделаться от парня за 10 дней»). Вертикаль 1080×1920, картинка во всю ширину чуть выше центра; хук — одна романтичная реплика из фильма со звуком, субтитры появляются по словосочетаниям в чёрном поле под кадром; музыка под репликой приглушена, сразу после — дроп и склейки на каждый бит; тёплый мягкий грейд со свечением (romcom glow), улыбки, взгляды, финал — поцелуй; в конце маленький ник на чёрном с тёплым свечением (@editsfrgrl).

## Examples

- «Сделай эдит про Райана Гослинга»: хук-фраза из интервью (№7–9), заголовок «THE MANY FACES OF …» по словам (№11), крупные планы ролей с угловыми подписями (№11), одна страница-коллаж с белой вспышкой (№6), ник в конце.
- «Вот ещё пример»: разобрать по той же схеме и добавить раздел №17.

## Разборы
Правило пользователя: каждый присланный ролик — пример. Не копировать один, а собирать лучшее из всех.
Тайминги замерены покадрово: склейки — scene-detect, бит — librosa, движение камеры — ORB, вспышки — по яркости кадра.
Хвост 3–5 с в конце каждого ролика — заставка TikTok, её добавляет платформа, в эдит не входит.

### 1. [мужской] Scarface с песней — @musafx (4:3, 22 с, ~136 BPM). Первый пример, по нему сделан эдит с Макконахи
- Вступление: слова песни по одному по центру, мелкий белый текст; акцентные слова на 3 кадра крупно и цветом (красный, жёлтый, оранжевый).
- Дроп на 6,3 с: 1 белый кадр, затем склейки на каждый бит.
- Белые вспышки: ровно 1 кадр чистого белого, следующий кадр уже чистый.
- Переход: белый квадрат → маленькое окно-вставка со следующим кадром → белая вспышка → полный кадр.
- Второй круг (13,4 с) повторяет цепочку кадров; в конце ник на чёрном.

### 2. [мужской] The Mentalist (Саймон Бейкер) — @tekno_edit (1:1, 16 с, ~85 BPM)
- Спокойный «харизматичный» эдит без текста и без вспышек.
- Склейки строго каждые 0,70 с.
- На склейках лёгкие наезды/отъезды (зум ±1–2%) и поворот на 1–2,5°: мягкие «доводки», а не тряски.
- Цепочка из ~11 кадров проигрывается дважды (0–8 с и 8–16 с).
- Цвет: холодный, приглушённый, серо-бирюзовый; сам кадр всё время из одного сериала.

### 3. [мужской] «Духless» — @elegantbaza (16:9, 45 с). Кинетическая типографика

- Текст стоит рядом с говорящим, позиция меняется от фразы к фразе.
- Огромные полупрозрачные светло-серые слова на весь кадр на акцентах («БУМАЖКИ», «БАБКИ», «СУКА»).

### Предпочтения пользователя
- Только HD-исходники, без видимой пикселизации и без апскейла из низкого разрешения.
- Источники: clip.cafe (поиск по фразе, часть фильмов в 4K — сначала проверять там), YouTube через vidIQ video_upload (бесплатно, 1080p), трейлеры 1080p на Dailymotion.
- Pinterest: видео максимум 720p и сильно сжаты (~0,5 Мбит/с) — для кадров из фильмов хуже clip.cafe и YouTube; зато фото там бывают в оригинальном разрешении — брать для карточек (№6–9). Поиск только через headless Chromium (страница рендерится скриптом).
- На YouTube-клипах проверять логотипы каналов-загрузчиков в углах кадра и кадрировать их.
- Музыка: из присланного примера или с YouTube через vidIQ edit_media extract_audio в WAV (1 кредит); трендовые звуки — vidiq_tiktok_trending_sound_search. Текст песни на экран не выводить.
- Вид для TikTok: 1080×1920, картинка 16:9 во всю ширину на 40 px выше центра, сверху и снизу чёрное.
- Подпись автора в конце: мелко, полупрозрачно, на чёрном (@editfrmn).
- Звуки «вжух» не нужны. Тряски — только на акцентах. Выстрел — один.
